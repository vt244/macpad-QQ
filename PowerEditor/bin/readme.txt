macpadqq
========

macpadqq is a native macOS code and text editor. It is an independent
fork of Notepad++, originally created by Don Ho and developed by its
contributors. The editor uses AppKit, Scintilla Cocoa and Lexilla.

Open macpadqq.app in Finder. Use File > Open to edit a file. Add themes
in View > Theme and translations in Settings > Interface Language.
The profile is under ~/Library/Application Support/macpadqq/profile/.

Source, build instructions, and issues:
https://github.com/vt244/macpad-QQ
